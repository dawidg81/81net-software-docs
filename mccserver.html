Minecraft Classic 0.30 server

dawidg81 in 2026.09.03

We will make a Minecraft Classic c0.30 server software.

Such server software should handle basic information on world data, player position and chat. It runs most of the game logic while the client (c0.30, ClassiCube) handles displaying everything graphically, handling player movement, etc.

We can see that the server relatively doesn't need much to handle whole game. Such universality and extensibility allows us to implement any mini-game/gamemode that fits into the voxel engine environment. The most popular gamemode implemented into many server softwares of such type is of course creative or survival.
