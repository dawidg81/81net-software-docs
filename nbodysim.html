Let's take a look at what is n-body simulation.

Three-body problem: We have three point masses orbiting each other in space. Every tick, frame, or as fast as our computer can, we calculate their trajectories using Newton's laws of motion and law of universal gravitation. Each body has these parameters:

		X position
		Y position
		X velocity
		Y velocity
		Mass

Each parameter can be saved as double data type in the program. We create three bodies with different parameters:

		{ 0.0, 0.0, 0.0,  0.0,    1000.0 },
		{ 1.0, 0.0, 0.0,  1.0,    1.0 },
		{-1.0, 0.0, 0.0, -1.0,    1.0}
